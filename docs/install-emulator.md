# 模拟器（Eden / Yuzu / Sudachi）安装指南

适用于支持 Switch mod 加载的模拟器，Windows / macOS / Android 均可。

## 前置条件

- Eden / Yuzu / Sudachi 等支持 Switch mod 的模拟器
- 游戏本体《寒蝉鸣泣之时奉》，Title ID `0100F6A00A684000`
- 游戏版本与补丁匹配：**V2.2 → 2.0.0 / 2.0.2**；**V1.1 → 1.0.0 / 1.2.0**

## 步骤

1. 关闭游戏，确认游戏版本与补丁匹配。
2. 在模拟器里**右键该游戏**，选择「**打开 Mod 数据目录**」。
3. 新建一个文件夹（名字随意，例如 `higurashi_cn`）。
4. 解压补丁包，打开 `Emulator_Mod_模拟器直接加载/`，把里面的 `romfs` 和 `exefs` 两个文件夹**整体放进**第 3 步建的文件夹。
5. 启用该模组，并**停用本游戏的旧汉化模组**，避免重复覆盖。
6. 启动游戏。

## 注意

- 最终结构应类似 `load/0100F6A00A684000/higurashi_cn/romfs/` 与 `.../exefs/`。
- 如果你的模拟器支持直接导入文件夹或压缩包，也可以直接导入。
- 模拟器和实机两种安装目录**选对应的一份即可**，不需要同时安装。
